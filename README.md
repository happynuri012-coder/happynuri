# 해피누리 공식 홈페이지 초안

## 파일 구성
- `index.html`: 홈페이지 본문
- `styles.css`: 반응형 디자인 및 CI 색상
- `script.js`: 모바일 메뉴 및 연도 자동 표시
- `assets/favicon.svg`: 브라우저 아이콘
- `assets/happy-nuri-logo-reference.jpg`: 제공받은 CI 이미지 참고용 크롭

## 실행 방법
`index.html` 파일을 브라우저로 열면 정적 홈페이지를 확인할 수 있습니다.
인터넷 폰트는 Google Fonts를 사용하며, 네트워크가 없으면 시스템 글꼴로 표시됩니다.

## 공개 방법
이 사이트는 정적 HTML/CSS/JS이므로 정적 호스팅에 올릴 수 있습니다. 예: Cloudflare Pages, Netlify, GitHub Pages 또는 일반 웹호스팅.
실제 도메인 연결에는 도메인 관리 화면의 DNS 설정과 호스팅 계정 접근이 필요합니다.

## 공개 전 확인할 사항
1. 회사 공식 주소 및 대표 연락처 공개 여부
2. 회사 소개 문구 및 서비스 상태(운영 중/준비 중) 최종 확인
3. 사업자 정보/개인정보 처리방침 등 사이트 성격에 필요한 고지
4. 실제 CI 원본 벡터 파일이 있으면 로고 영역을 정식 로고 파일로 교체
5. 문의 폼이 필요하면 메일 연동 또는 서버 측 폼 서비스 연결

## 주의
현재 문의 기능은 이메일 앱을 여는 `mailto:` 링크입니다. 서버로 문의 내용을 저장하는 폼은 아직 연결되어 있지 않습니다.
